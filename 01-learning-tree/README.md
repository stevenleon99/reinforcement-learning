# Learning Tree (Visual Roadmap)

> Map section: [RL_LEARNING_MAP.md - Section 1](../RL_LEARNING_MAP.md#1-learning-tree-visual-roadmap)

## What This Module Covers

The full visual roadmap from Stage 0 (Prerequisites) through Stage 6 (Domain Applications). Use this as your navigation hub to understand the learning progression.

## Key Topics

- Stage 0: Prerequisites (Python, Math, ML basics)
- Stage 1: Core RL Concepts (Agent, Environment, Policy, Value)
- Stage 2: Classic RL (DP, Monte Carlo, TD Learning)
- Stage 3: Deep RL (DQN, Policy Gradient, Actor-Critic)
- Stage 4: Modern RL & LLM Alignment (PPO, DPO, GRPO, RLHF)
- Stage 5: Advanced & Research (Model-Based, Offline, Multi-Agent, Meta-RL, Inverse RL)
- Stage 6: Domain Applications (Robotics, Finance, Games, LLMs)
