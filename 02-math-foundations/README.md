# Mathematical Foundations

> Map section: [RL_LEARNING_MAP.md - Section 2](../RL_LEARNING_MAP.md#2-mathematical-foundations)

## What This Module Covers

All the mathematical prerequisites needed to understand and implement RL algorithms. These foundations are non-negotiable -- every RL algorithm builds on them.

## Submodules

| Submodule | Folder | Topics |
|-----------|--------|--------|
| Linear Algebra | [./linear-algebra/](./linear-algebra/) | Vectors, matrices, eigenvalues, SVD |
| Probability & Statistics | [./probability-statistics/](./probability-statistics/) | Distributions, Bayes, expectation, Monte Carlo |
| Calculus & Optimization | [./calculus-optimization/](./calculus-optimization/) | Gradients, SGD, convexity, Lagrangians |
| Markov Decision Processes | [./mdps/](./mdps/) | MDP formalism, Bellman equations |

## Suggested Exercises

- Implement matrix operations in NumPy from scratch
- Derive the Bellman equation step by step
- Code a simple gradient descent optimizer
- Build a Markov chain simulator
