# RL for Games

> Map section: [RL_LEARNING_MAP.md - Section 9.4](../RL_LEARNING_MAP.md#94-rl-for-games)

## What This Module Covers

RL applied to game playing and game development: from AlphaGo to modern NPC behavior and procedural generation.

## Key Topics

- AlphaGo / AlphaZero / MuZero
- OpenAI Five (Dota 2), AlphaStar (StarCraft II)
- RL for game testing
- NPC behavior and procedural content generation
- Multi-agent frameworks (PettingZoo, Melting Pot)

## Suggested Resources

- PettingZoo (multi-agent environments)
- Melting Pot (social dilemmas)
- CleanRL game examples

## Suggested Exercises

- Train an agent on a simple board game
- Implement a multi-agent cooperative task with PettingZoo
- Build a self-play training loop
