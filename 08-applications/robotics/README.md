# RL for Robotics

> Map section: [RL_LEARNING_MAP.md - Section 9.1](../RL_LEARNING_MAP.md#91-rl-for-robotics)

## What This Module Covers

Applying RL to physical robots: locomotion, manipulation, and the critical challenge of sim-to-real transfer.

## Key Topics

- Legged locomotion (ANYmal, Unitree)
- Dexterous manipulation (OpenAI, NVIDIA)
- Sim-to-Real transfer (domain randomization, system ID)
- Isaac Gym (NVIDIA GPU-accelerated simulation)
- MuJoCo physics simulation

## Suggested Resources

- Isaac Gym (NVIDIA)
- MuJoCo, Gymnasium-Robotics
- OpenAI: "Solving Rubik's Cube with a Robot Hand"

## Suggested Exercises

- Train a walking policy in Isaac Gym
- Implement domain randomization for sim-to-real
