## What This Module Covers

How RL is applied in real-world domains: robotics, finance, games, and LLM alignment. Includes current industry trends for 2024-2025.

## 2024-2025 Trends

1. DPO replacing PPO for alignment
2. GRPO gaining adoption (memory efficiency)
3. Reasoning with RL (DeepSeek-R1, OpenAI o1)
4. RL from AI Feedback (RLAIF)
5. Offline RL for fixed datasets
6. Multi-agent RL
7. Foundation models + RL
